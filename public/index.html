A few things to know.

Can I build and publish a website today?

Yes, if you have an invitation. You can build a simple site with text and photos, preview changes privately, and confirm publication to a TellUmo test address. Uploads stay private until you publish a version containing them. Forms, custom domains, and custom backend features are still being built.

How do I join the test?

You’ll need an invitation code from the TellUmo team. Choose “Use your invitation” and enter your code when creating your account. Already joined? Sign in to return to your workspace.

Is TellUmo the final name?

It’s our working name while we build. For now, digifender.com is the home of the test platform.
