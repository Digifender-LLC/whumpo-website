# Security policy

Whumpo is a private test-stage platform with no production customers. Only the current `main` branch is supported.

## Reporting a vulnerability

Do not open an issue or pull request describing the problem. Contact the repository owner, [@zemdregon](https://github.com/zemdregon), directly with the affected component, steps to reproduce and impact. Never include live credentials or customer content in a report.

Incident handling and data protection are described in [docs/incident-runbooks.md](docs/incident-runbooks.md) and [docs/data-protection.md](docs/data-protection.md).
