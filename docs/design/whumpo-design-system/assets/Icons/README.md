# Icons

Rounded 2px-stroke icons on a 24px grid. These files are single ink, stroked in Deep Sky `#0F2D5B` (they cannot inherit color via `<img>`); for other colors use the `Icon` component, which draws the same paths in `currentColor`. Provisional set drawn for this system.

- `home.svg` — website · `globe.svg` — domain · `database.svg` — database · `storage.svg` — file storage · `server.svg` — capacity/compute
- `person.svg` — account, customers · `chat.svg` — conversation · `spark.svg` — ideas, delight, new
- `check.svg` — ready / done · `alert.svg` — needs attention · `clock.svg` — working · `send.svg` — send message
