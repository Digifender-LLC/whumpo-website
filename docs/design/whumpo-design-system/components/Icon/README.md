# Icon

Rounded-stroke icons for plain-language infrastructure metaphors, drawn in `currentColor`.

- Provide `name` (see `window.Whumpo.icons`) and optionally `size` (default 20) and `title` when the icon stands alone and carries meaning.
- Name concepts the customer understands: home (website), globe (domain), database, storage, server, person, chat. Never provider logos.
- Use the elephant only as the brand mark, not as an icon.
