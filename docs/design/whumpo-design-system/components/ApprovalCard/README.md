# ApprovalCard

Asks before paid or risky work, stating outcome, price impact and risk in plain language.

- Provide `title`, `outcome`, `cost` ("About $84/month") and optional `risk`; `onApprove` / `onDecline`; labels default to "Approve" / "Not now".
- Never provision paid resources without this card or an equivalent explicit yes. Keep the mascot off this screen.
