# Button

Pill-shaped buttons. **Primary** (Sky Blue with Deep Sky text) at most once per view, for the thing the screen is for.

- Provide `children` (verb first, sentence case: "Approve and continue"), `variant` (`primary`, `secondary` default, `quiet`), optional `icon` and `size="sm"`.
- Never put white text on Sky Blue — it fails contrast; the component uses `on-action`.
- A button that spends money says so in the label or the card around it.
