## Method and limits

- **Files present:** every `docs/`, `tests/`, `tools/` and `src/` path named in the task's references, acceptance, verification, scope or outcome text, plus paths named in its evidence, was checked with `fs.existsSync`. "yes" means all of them exist; exceptions are named.
- **Merged evidence:** the PR or commit recorded in the task's own evidence, cross-checked against the commit that first added the task's documents to this history (`git log --diff-filter=A`). Commit hashes cited in evidence were not all verifiable: `git rev-list` aborted because `d27b46a` and `d9f5d26` do not resolve in this checkout, so the ancestry of the other cited hashes was not checked. Where the table says "history", the PR/commit comes from this checkout's git log, not from the task's evidence.
- **Offline check:** a test was run only if it imports `node:` built-ins or local files with no bare package specifiers. `node_modules` is absent and nothing was installed. Tests that import `esbuild`, `wrangler`, `miniflare`, `vite`, `fflate` or `typescript` were **not run**.
- Passing a contract test proves the frozen contract and its synthetic reference only, as each test's own output states. It is not provider, device or live acceptance.
