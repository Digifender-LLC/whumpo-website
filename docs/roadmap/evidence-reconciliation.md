## Method and limits

Population: all 78 backlog entries whose `evidence` array was empty at `ca17c6a` (the other 66 entries carry evidence that this slice did not audit). For each, in this order:

1. `git log origin/main --grep` for the task id, plus a search of `src`, `tests`, `tools`, `frontend`, `schema`, `android` and `docs` for the id.
2. Whether each `references` path exists on `main` (all do, for every checked entry).
3. Read-only `gh issue view`/`gh issue list`/`gh pr view`/`gh pr list` on `zemdregon/whumpo` for the mapped or title-matched issue and open pull requests.
4. Re-running cheap offline checks named in the task, after reading each test header: disposable SQLite or local D1 (`wrangler --local`, `remoteBindings:false`), fetch stubbed, no credentials, no remote Cloudflare/GitHub call.

Environment: Node 24.21.0, pnpm 11.19.0, Linux aarch64. Two browser/media tests needed tools the repo does not install: host `python3` lacks Pillow, so a PATH shim pointed to an existing virtualenv that has it; Playwright came from another local checkout through the documented `WHUMPO_PLAYWRIGHT` variable. Neither changed the repository.

Evidence vocabulary used below: **source** (code merged to `main`), **local** (passes on disposable fixtures), **configured/deployed** (not observed here), **live/device accepted** (not claimed anywhere in this slice). A merged commit or a closed issue is a pointer, not proof, and planning readiness is never completion.
