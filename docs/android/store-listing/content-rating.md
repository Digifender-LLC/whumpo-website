# Play content rating questionnaire: draft answers

**Status, October 29, 2026: draft for the owner to enter in Play Console (Policy and programs, App content, Content ratings).** The IARC questionnaire is per app and must be answered truthfully by the owner. Category: **Utility, productivity, communication or other** (not game, not social, not news).

| Question | Answer | Why |
| --- | --- | --- |
| Violence (any kind) | No | Whumpo is a business-tools app. |
| Blood, gore | No | |
| Sexual content or nudity | No | |
| Profanity or crude humour | No | |
| Controlled substances (alcohol, tobacco, drugs) shown or promoted | No | The app itself shows none. Customer websites are the customer's own and are opened in the browser. |
| Gambling or simulated gambling | No | |
| Fear or horror themes | No | |
| Discrimination, hate, bullying content | No | |
| Real-money transactions or purchases | No | Real payments are disabled in the beta. Revisit when billing ships. |
| Users can interact or exchange content with other users | **No** | Chat is between one owner and Whumpo. There is no user-to-user messaging, feed or public profile. |
| Users can share their location | No | No location permission. |
| Unrestricted web access | No | The app opens specific Whumpo pages in Custom Tabs; it has no address bar. |
| Shares personal information with third parties | Follow the [Data safety draft](data-safety.md) | |
| Generative AI | **Yes** | Chat uses AI to prepare site changes. A person must approve every change before it goes live. Users can contact support from Settings. |

Expected rating: Everyone / PEGI 3 / IARC 3+. The generative AI answer can add a regional note; accept what IARC returns.

Also in App content: target audience **18 and over** (business owners; not directed at children), no ads, not a news app, not a government app, no health features, no financial-features declaration needed while real payments are off. A privacy policy URL is required.
