# Store listing screenshots

Generated by the Roborazzi harness (`storeListing` tests in `ScreensScreenshotTest` and `ChatScreenshotTest`, helper `captureStore` in `RobolectricSupport.kt`), with the same synthetic fixtures as the other goldens (Example Detailing, Corner Bakery orders, Garden club newsletter; `example.test` addresses). No real data. CI verifies them on every run, so they cannot drift from the UI. To re-record, run the Android workflow by hand with `record_screenshots=true`, download the `android-screenshot-goldens` artifact and copy `docs/android/store-listing/screenshots/` over this folder.

| Folder | Pixels | Use in Play Console |
| --- | --- | --- |
| `phone/` | 1080 x 1920 | Phone screenshots |
| `tablet7/` | 1200 x 1920 | 7-inch tablet screenshots |
| `tablet10/` | 1600 x 2560 | 10-inch tablet screenshots |

Each name ends in `-light` or `-dark`. Phone: `1-chat`, `2-projects`, `3-project-detail`, `4-activity`. Tablets: `1-chat`, `2-project-detail`, `3-activity` (the projects list is a single narrow column below 840 dp, so the detail view tells the story better on a tablet).

Play wants 2 to 8 screenshots per device type; upload the light set first and the dark set as extras, or choose either. The frames are the app content only, with no device bezel, status bar or navigation bar. Tablet frames are portrait.

Known gaps: the screens are the stateless content composables, so the bottom navigation bar is not drawn; a framed marketing version with captions is a design task. The Activity "A change is ready for your review" banner is left out because its **Dismiss** label has low contrast in dark mode (a UI bug to fix separately).
