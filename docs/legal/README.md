# Whumpo policy sources

These six Markdown documents are the editable source for the company-hosted [Whumpo policy collection](https://digifender.com/legal/whumpo). The Digifender website builds its Whumpo web, print, and PDF copies from this directory in a Whumpo checkout.

The documents remain **drafts for review**. Versioning them here does not adopt an agreement, enable an acceptance flow, establish company formation, or verify the operational promises in the text. Review the relevant legal and operational requirements before adopting or changing public status.

Edit policy wording here, then rebuild and verify the Digifender site before publishing it. Keep the product name, draft label, web page, print view, and PDF in sync. The company website's `WHUMPO_LEGAL_SOURCE` setting can point its build at a different Whumpo checkout when needed.
